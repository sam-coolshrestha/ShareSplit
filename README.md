# ShareSplit

ShareSplit is a modern expense-sharing and group settlement platform designed to simplify splitting bills, tracking shared expenses, and settling balances with friends and groups.

Built with a mobile-first approach, ShareSplit combines a modern user experience with powerful financial tracking features including group expenses, debt simplification, friend balances, and UPI-based settlements.

## Features

### Authentication

* Email & Password Authentication
* Google OAuth Login
* Secure session management with Supabase
* Protected routes and dashboard access

### Group Expense Management

* Create and manage expense groups
* Invite members via email
* Track group expenses and balances
* View group members and expense history

### Expense Splitting

* Equal Split
* Custom Split (amount or percentage based)
* Itemized Split
* Expense categorization
* Notes and payment tracking

### Balance Calculation

* Real-time balance tracking
* Debt simplification algorithm
* Optimized settlement recommendations
* Settlement history tracking

### UPI Settlements

* Google Pay integration
* PhonePe integration
* Paytm integration
* Pre-filled UPI payment links
* Settlement recording and history

### Friends & Activity

* Friend balance tracking
* Shared expense history
* Global activity feed
* Timeline-based transaction history

### User Experience

* Dual Theme System

  * Comic Mode
  * Modern Mode
* Responsive mobile-first design
* Animated navigation and interactions using Framer Motion
* Progressive Web App (PWA) support
* Real-time synchronization using Supabase Realtime
